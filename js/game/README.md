# js/game/ — as regras

| Arquivo | Para quê |
|---|---|
| `app-play.js` | a consulta (conversa, ficha, Manual, hipótese, resultado, intervalo, modo secreto) |
| `dxlab.js` | investigação clínica: Investigar, ficha em 5 abas, 5 Ps, hipóteses, revisão do diagnóstico |
| `followup.js` | acompanhamento em 4 semanas e 4 consultas por paciente, encaminhamento |
| `quests.js` | menu de Missões |
| `activities.js` | atividades interativas: pescaria, escavar conchas, buscar a bolinha |
| `app-shop.js` | lojas e provador |
| `app-extras.js` | bichinhos, souvenirs, botons |
| `decor.js` | organizar os móveis (planta do cômodo) |
| `charedit.js`, `player.js` | criação e edição da personagem |
| `pins.js` | botons, bandeiras, óculos e bijuterias |
| `phone.js` | celular (mensagens, agenda, prontuário, amigos) |
| `wheel.js` | roda do psicólogo (perfil dominante) |
| `minigames.js` | Ludoteca da Mente (10 minijogos) |
| `faunaguide.js` | guia da fauna |
