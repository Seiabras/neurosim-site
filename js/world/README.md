# js/world/ — a cidade

| Arquivo | Para quê |
|---|---|
| `city.js` | o motor da cidade em 2D: andar, ruas, mapa, conversas, lojas |
| `city-art.js` | desenhos em vetor: fachadas, casas, barcos, criaturas |
| `town.js` | pessoas andando com rotina, convencer moradores, figuras especiais |
| `life.js` | saúde, academia, cassino, obras, guardiões, conquistas |
| `places.js` | cartões de aprendizagem dos lugares novos (laboratório, museu, escola...) |
| `culture.js` | lojinha de idiomas e história da psicologia |
| `aquarium.js`, `aquarium-data.js` | aquário: lógica e dados (espécies, tanques, peças) |
| `fauna.js`, `nature.js` | bichinhos e plantas de enfeite dos lugares |
